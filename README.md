- 🤖 Currently exploring **transformers (DistilBERT)** and **LLM apps with LangChain**.

### 🚀 Featured projects

| Project | What it does | Stack |
|---|---|---|
| [**Mental Health Text Classification**](https://github.com/ovibaridar/Analysis-/tree/main/Mental_Health_Classification) | Hybrid deep model that combines DistilBERT embeddings with a 1D-CNN to classify mental-health status from text | PyTorch, Transformers, TensorFlow, NLTK |
| [**Student Dropout Risk Prediction**](https://github.com/ovibaridar/Analysis-/tree/main/Student%20Drop%20out%20risk) | Predicts students at risk of dropping out using a stacking ensemble, with SHAP explanations | scikit-learn, XGBoost, CatBoost, SHAP |
| [**Pharmaceutical Sales Forecasting**](https://github.com/ovibaridar/Models/tree/main/Pharmaceutical%20Sales%20Forecasting) | Time-series forecasting of weekly drug sales by category | Keras (LSTM), XGBoost, Prophet, ARIMA |
| [**Amazon Review Sentiment Analysis**](https://github.com/ovibaridar/Amazon_Review_Classification_for_Sentiment_Analysis) | Classifies Amazon food reviews as positive/negative using TF-IDF and classic ML models | NLTK, scikit-learn, imbalanced-learn |
| [**Gender Recognition by Voice**](https://github.com/ovibaridar/Gender_Recognition_by_voice_with_model) | Predicts speaker gender from audio features, with a Tkinter desktop app for testing | librosa, scikit-learn, Tkinter |
| [**CareLink**](https://github.com/ovibaridar/CareLinkWeb) | Marketplace web app connecting customers with verified in-home care providers, with booking and calendars | Django, Tailwind CSS, SQLite |
